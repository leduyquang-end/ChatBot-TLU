# events/ — Nơi xử lý sự kiện (chưa dùng)

## Mục đích

Folder này dành cho tính năng "sự kiện" — khi có gì đó xảy ra, chương trình "bắn tin" cho các bộ phận khác biết để xử lý (ví dụ: ghi log đăng nhập, thông báo khi nạp tri thức xong).

Hiện tại **chưa dùng** — để trống chờ mở rộng.

## Khi nào cần dùng

Khi muốn: "Mỗi lần có người đăng nhập, tự động ghi lại vào sổ nhật ký" mà không cần sửa code đăng nhập — chỉ cần "nghe" sự kiện.
